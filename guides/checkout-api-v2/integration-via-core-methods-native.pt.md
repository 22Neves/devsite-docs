# Métodos Core (Native)

Neste método de integração, a pessoa responsável pela integração tem controle total sobre como as informações necessárias para completar o pagamento serão capturadas e processadas, utilizando os campos seguros e métodos core fornecidos pela SDK Nativa do Mercado Pago.

Na integração via Métodos Core, você decide quando buscar as informações sobre o tipo de documento, além das informações do cartão (emissor e parcelas). Com isso, possui total flexibilidade na construção da experiência do fluxo de checkout em aplicativos nativos.
