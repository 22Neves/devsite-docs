# Acompanhamento do status dos arquivos enviados 

É possível acompanhar os arquivos enviados através da página de [Status de processamentos em batch](https://www.mercadopago[FAKER][URL][DOMAIN]/batch-payments).

Além disso, você receberá comunicações no e-mail registrado durante o processo de onboarding, incluindo um e-mail confirmando o recebimento correto do arquivo e o início do processamento.

Também será enviado um e-mail informando sobre a conclusão do processamento.
