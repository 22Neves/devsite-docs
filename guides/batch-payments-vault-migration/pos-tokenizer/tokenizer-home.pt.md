# Home do Tokenizador

Acesse os Tokenizadores através da opção **Televendas**, que deve ser previamente habilitada para essa conta. Para acessar, entre no Mercado Pago e vá para a opção **Televendas** dentro do menu lateral esquerdo.

Existem duas opções para criar vinculações de pagamento:
1. O vendedor ou colaborador insere manualmente os dados dos cartões físicos.
2. O vendedor gera um link de convite e o compartilha com o pagador, permitindo que este insira os dados do cartão diretamente.

![](/images/batch-payments/generate-tokens.png)

## O vendedor insere os dados do cartão manualmente

1. Depois de escolher a opção **Tenho os dados para registrá-los agora**, insira os dados do cartão e do usuário.

![](/images/batch-payments/card-data.png)

2. Após inseri-los, o token será gerado automaticamente.

![](/images/batch-payments/copy-data.png)

3. Na próxima tela, é possível ver, copiar e excluir todos os tokens gerados.

![](/images/batch-payments/history-tokens.png)

## O pagador insere os dados do cartão diretamente

1. Depois de escolher a opção **Tenho que pedir os dados ao cliente**, o vendedor deverá inserir a identificação do pagador em seu sistema.

![](/images/batch-payments/ask-token.png)

2. Após a identificação, o convite é gerado e compartilhado com o pagador.

![](/images/batch-payments/send-link.png)

3. Na próxima tela, é possível ver, copiar e excluir todos os convites gerados.

![](/images/batch-payments/history-tokens-2.png)

4. Após receber o link compartilhado pelo vendedor, o pagador será direcionado para uma tela de onboarding, onde deverá clicar em **Continuar** para prosseguir.

![](/images/batch-payments/register-card.png)

5. O pagador poderá inserir os dados do seu cartão, juntamente com seu e-mail e número de documento.

![](/images/batch-payments/complete-data.png)

6. Pronto! A vinculação do cartão foi criada com sucesso e estará disponível na tabela de Tokens Gerados.

![](/images/batch-payments/success-send-data.png)

> NOTE
> 
> Importante
> 
> Os links possuem validade de 7 dias ou até serem utilizados.
