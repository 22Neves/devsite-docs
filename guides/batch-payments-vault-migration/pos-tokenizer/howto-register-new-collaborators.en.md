# How to register new collaborators

1. Go to **Your business > Collaborators**.
2. Click on **Create role** to create a role.
3. Assign a name to the new role and select the permissions for Mercado Pago.
4. Expand **Collections and Post-Sales**.
5. Check the box for the option **Charge Services by Tele-sales**.
6. Select the activities that the collaborator will be able to see.
7. Click on the **Create role** button to complete the process of creating a new role.
