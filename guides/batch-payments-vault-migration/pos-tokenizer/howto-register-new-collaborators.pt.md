# Como registrar novos colaboradores

1. Acesse **Seu negócio > Colaboradores**.
2. Clique em **Criar papel** para criar um papel.
3. Atribua um nome ao novo papel e selecione as permissões para o Mercado Pago.
4. Abra **Cobranças e pós-vendas**.
5. Marque a caixa da opção **Cobrar serviços por Tele-vendas**.
6. Selecione as atividades que o colaborador poderá ver.
7. Clique no botão **Criar papel** para finalizar o processo de criação de um novo papel.
