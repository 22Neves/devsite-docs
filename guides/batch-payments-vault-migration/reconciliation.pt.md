# Conciliação

Para a conciliação de pagamentos, temos disponíveis os relatórios de conciliação do Mercado Pago em sua conta.

O relatório de [Dinheiro na conta](https://mercadopago.com.ar/developers/es/docs/links-and-debts/additional-content/reports/account-money/introduction) permite acessar os detalhes de cada movimentação na conta. Na mesma página, é possível configurar um repositório SFTP personalizado para receber o relatório e determinar a frequência com que você deseja gerar as informações.
