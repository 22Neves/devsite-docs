 - title: Batch Payments
 - message: Mercado Pago's Batch Payments are a practical and secure solution for making mass payments. With this tool, companies can manage recurring payments without the need for complex integrations with APIs, simplifying the process of financial transactions. The functionality allows generating and managing payment recurrence by importing .csv files sent to an SFTP server, making financial management more efficient and streamlined. Mercado Pago processes these payments through multi-acquiring and returns a file that presents the status of each payment made, providing clear and detailed control of financial operations.

bullet_section_with_media:
 - title: Advantages
 - type: reverse
 - message:
 - image: /batch-payments/landing2.png
 - benefit_title: Mass Payments
 - benefit_message: Batch Payments allows companies to process large volumes of payments simultaneously, saving time and effort when managing large-scale transactions.
 - benefit_title: 24/7 Availability
 - benefit_message: Batch Payments does not limit collection attempts; they can be made every day, more than once a day. This ensures more approvals and customer funds in the company's account more quickly.
 - benefit_title: Process Simplification
 - benefit_message: Without the need to develop integrations through APIs, companies can save development resources and accelerate the implementation of the payment system.
 - benefit_title: Security through Tokenization
 - benefit_message: By operating with tokenized data (customer_id and card_id) instead of sensitive card information (PAN), Batch Payments offers greater security in transactions.
 - benefit_title: 1:N Relationship
 - benefit_message: With the structure of customer_id and card_id, the system allows a seller to link multiple cards to a single payer. This is useful in situations such as vault migrations, where the seller can associate various cards with the same payer, identified by an email.
