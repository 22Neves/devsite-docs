# Prerequisites

To utilize refunds through the batch flow, the following is necessary:

| Requirement | Description |
|---|---|
| Batch collection service | To process refunds, it is necessary to be using the batch collection service. **Important:** Refunds are allowed exclusively for payments made through the batch. The same account and application that were used to generate the batch payments must be used. |

Next, along with the SFTP, we will return the following connection data:

| Connection data | Description |
|---|---|
| UserName | Username required for the SFTP connection |
| Host | Server connection URL |
