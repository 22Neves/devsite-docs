# Requisitos previos

Para utilizar los reembolsos a través del flujo en batch, es necesario:

| Requisito | Descripción |
|---|---|
| Servicio de cobranza en batch | Para realizar los reembolsos, es necesario estar utilizando el servicio de cobranza en batch. **Importante:** los reembolsos están permitidos exclusivamente para los pagos realizados a través del batch. Se debe usar la misma cuenta y la misma aplicación con la que se generaron los cobros por pagos en batch. |

A continuación, junto con el SFTP, devolveremos los siguientes datos de conexión:

| Datos de conexión | Descripción |
|---|---|
| UserName | Nombre de usuario necesario para la conexión al SFTP |
| Host | URL de conexión del servidor |
