# Requisitos prévios

Para utilizar os reembolsos através do fluxo em batch, é necessário:

| Requisito | Descrição |
|---|---|
| Serviço de cobrança em lote | Para realizar os reembolsos, é necessário estar utilizando o serviço de cobrança em lote. **Importante:** os reembolsos são permitidos exclusivamente para pagamentos realizados através do lote. Deve-se usar a mesma conta e a mesma aplicação com a qual foram geradas as cobranças por pagamentos em lote. |

A seguir, junto com o SFTP, devolveremos os seguintes dados de conexão:

| Dados de conexão | Descrição |
|---|---|
| UserName | Nome de usuário necessário para a conexão ao SFTP |
| Host | URL de conexão do servidor |

> NOTE
> 
> Nota
> 
> O carregamento de arquivos está disponível 24 horas por dia, 7 dias por semana, e o período de processamento é imediato.
