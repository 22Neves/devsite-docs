# Reconciliation

For payment reconciliation, we have Mercado Pago reconciliation reports available in your account.

The [Account money](https://mercadopago.com.ar/developers/es/docs/links-and-debts/additional-content/reports/account-money/introduction) report allows you to access the details of each transaction in your account. On the same page, you can set up a custom SFTP repository to receive the report and determine the frequency at which you want to generate the information.
