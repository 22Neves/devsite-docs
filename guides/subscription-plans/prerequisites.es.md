# Requisitos previos

Para crear un plan de suscripción, deberás cumplir con el siguiente requisito previo:

| Requisito | Descripción |
|---|---|
| Cuenta de Mercado Pago | Para recibir pagos recurrentes, necesitas una cuenta en Mercado Pago. Si no tienes una, accede al [sitio oficial de Mercado Pago](https://www.mercadopago[FAKER][URL][DOMAIN]/hub/registration/landing) para crearla gratis. |
