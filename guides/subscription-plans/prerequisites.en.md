# Prerequisites

To create a subscription plan, you must meet the following prerequisite:

| Requirement | Description |
|---|---|
| Mercado Pago Account | To create a subscription plan, you need a Mercado Pago account. If you do not have one, visit the [official Mercado Pago site](https://www.mercadopago[FAKER][URL][DOMAIN]/hub/registration/landing) to create it for free. |
