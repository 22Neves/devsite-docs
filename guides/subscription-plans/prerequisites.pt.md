# Requisitos prévios

Para criar um plano de assinatura, você deve atender ao seguinte requisito:

| Requisito | Descrição |
|---|---|
| Conta do Mercado Pago   | Para criar um plano de assinatura, você precisa de uma conta no Mercado Pago. Se você não tiver uma, acesse o [sitio oficial do Mercado Pago](https://www.mercadopago[FAKER][URL][DOMAIN]/hub/registration/landing) para criá-la gratuitamente. |
