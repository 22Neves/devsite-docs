# Transferências SPEI

Com o Checkout API do Mercado Pago, também é possível oferecer pagamentos por meio de Transferências SPEI, serviço que permite realizar pagamentos de qualquer banco ou instituição financeira utilizando a CLABE (Chave Bancária Padronizada).
